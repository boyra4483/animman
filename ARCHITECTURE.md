# 🧱 Архитектура проекта Animan

Проект построен по принципу **monorepo** — все приложения и пакеты хранятся в одном репозитории.

## 📁 Структура проекта

```bash
/apps
  ├─ tma      # Telegram Mini App (фронтенд-приложение)
  ├─ server   # Backend API (Express.js + Prisma)
  └─ bot      # Telegram-бот (для взаимодействия и рекомендаций)

/packages
  ├─ shared   # Общие типы, утилиты, константы
  └─ config   # Общая конфигурация: Webpack, ESLint и пр.
```

---

## ⚙️ Таблица стеков и технологий

### 🧩 Frontend (TMA — Telegram Mini App)

| Технология     | Назначение                                            |
| -------------- | ----------------------------------------------------- |
| **TypeScript** | Статическая типизация, предотвращение ошибок          |
| **React**      | UI-библиотека для построения компонентов              |
| **Redux**      | Централизованное управление состоянием                |
| **SCSS**       | Стили с поддержкой вложенности, переменных и миксинов |
| **HTML**       | Разметка приложения                                   |
| **Webpack**    | Сборка frontend-приложения                            |
| **FSD**        | Feature-Sliced Design — модульная архитектура проекта |

---

### 🛠 Backend (API-сервер)

| Технология     | Назначение                                       |
| -------------- | ------------------------------------------------ |
| **Node.js**    | Среда выполнения JS/TS на сервере                |
| **Express.js** | Минималистичный фреймворк для REST API           |
| **PostgreSQL** | Реляционная СУБД для хранения данных             |
| **Prisma ORM** | ORM для работы с PostgreSQL, миграции, типизация |
| **JWT**        | Авторизация через JSON Web Tokens                |
| **Cookie**     | Хранение JWT в HTTP-only cookies                 |
| **Axios**      | Запросы к стороннему API Anilibria               |
| **Railway**    | Хостинг и CI/CD для backend-сервиса              |

---

### 🤖 Telegram-бот

| Технология     | Назначение                              |
| -------------- | --------------------------------------- |
| **grammY**     | Telegram Bot API-фреймворк с удобным DX |
| **Node.js**    | Среда выполнения                        |
| **PostgreSQL** | Хранение данных (общая БД с backend)    |
| **Prisma ORM** | Работа с БД                             |
| **Axios**      | Получение данных с Anilibria            |
| **Railway**    | Хостинг Telegram-бота                   |

---

### 🔗 Общее

| Компонент            | Назначение                                    |
| -------------------- | --------------------------------------------- |
| **Monorepo**         | Централизованное хранение всех частей проекта |
| **/packages/shared** | Общие утилиты, типы, интерфейсы               |
| **/packages/config** | Общие конфиги Webpack, ESLint, Prettier и др. |

## 📡 Сторонние API

- [Anilibria API](https://github.com/anilibria/docs) — основной источник данных об аниме (поиск, тайтлы, новинки и т.д.)

---

## 🔗 Общие пакеты

- `/packages/shared` — переиспользуемые типы, утилиты, интерфейсы
- `/packages/config` — конфигурация сборщиков и линтеров (Webpack, ESLint и т.д.)

---

## 📌 Возможности

- Монолитная структура через **monorepo**
- Разделение слоёв по FSD
- Повторное использование логики между ботом и приложением
- Гибкая архитектура для расширения (рекомендации, избранное и т.д.)
